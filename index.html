⏳
รอ Pinterest อนุมัติ API
สมัครแล้ว กำลังรอ review อยู่ ปกติใช้เวลา 1-7 วัน
พอได้รับอีเมลอนุมัติแล้ว กรอก App Secret ด้านล่างได้เลย

หา App Secret ได้ที่ developers.pinterest.com → My Apps → VGreyDigitalStudio Scheduler → Manage

รูปที่ generate จาก Mockup จะมาอยู่ที่นี่ พอ Pinterest อนุมัติแล้วกดโพสได้เลย

📭
ยังไม่มีรูปในคิว
ไป Generate Mockup แล้วกด "เพิ่มในคิว" ได้เลย
1️⃣ รับอีเมลอนุมัติจาก Pinterest
2️⃣ ไปที่ developers.pinterest.com → Manage → copy App Secret
3️⃣ วาง App Secret ในช่องด้านบน → กด เชื่อมต่อ
4️⃣ Generate Mockup → กด "เพิ่มในคิว" → เลือก Board + เวลาโพส
5️⃣ ดูเวลาดาวมงคลจาก Planetary Hours แล้วตั้งเวลาได้เลย ✨
